## 2. 本轮真正完成的下界

在全部深度 n 的二进制词中，取零符号个数 `j_n=ceil(n ln2/ln3)`。对前缀定义

`D_k=(前 k 个符号中 0 的个数) ln3−k ln2=ln(2^k A_k)`。

这批词的总和 `D_n` 在 `[0,ln3)` 中。把每个词在其前缀和的最低点循环移位，可以让所有 `D_k≥0`；每个循环类至多 n 个词，因而保留至少 `binom(n,j_n)/n` 个不同词。这是经典循环移位方法的应用，不是新的组合定理。

取这些词对应的实际初态 `(1,y_w)`，其中 `y_w` 是深度 n 可行区间的中点；点距为 `2δ_n`。任何控制若首次在第 j 位与某个见证的可行词不同，全时域容差迫使该见证位于分界点单侧宽度不超过 `4δ_n` 的带中。因为共同前缀满足 `D_(j−1)≥0`，这个带宽对 j 和 n 统一。每个首次偏离位置至多有 3 个见证，一个控制总共至多覆盖 `3n+1` 个。

因此不是只数自然目录，而是对**每一个允许偏离 Q 的真实近似控制**证明

$$
r(n,2^{-n};Q)\ge\frac{\binom n{\lceil n\ln2/\ln3\rceil}}{n(3n+1)}.
$$

上界用完整停止树，精确可行前缀到达径向尺度 `δ_n/(2√2)` 后接 `1∞`，使所有后续时刻距离不超过 `δ_n/2`。用零符号概率 `ln2/ln3` 的 Bernoulli 权重给出 `N≤C exp(nH(ln2/ln3))`。二项式界使上下指数匹配。未来返回 Q 不能消除较早的违规，所以没有遗漏中间时刻；开邻域也没有等号漏洞。

没有用有限枚举、数值拟合或证明计划替代任何一步。此次主命题无保留的未证引理，指定极限无剩余上下界差距。

## 3. 扩张究竟改变了什么

扩张确实破坏了旧证明的两个统一条件：任意尾部收缩，以及所有停止圆柱的径向尺度/长度比较。但它没有在这个精度下造成新的成本下降。零符号频率接近临界值的控制词数量已经足够多；它们整体处于横向增长的临界点，又能排列成各前缀的横向总乘积均至少为 1 的形式。这一批难以合并的初态已经强迫完整成本率。

这与“把 R06 公式代入参数”不同：公式恰好给出同一数值，真正新增的是证明任意近似控制仍不能绕过这些见证。所得 `C n^3` 总目录比较也不声称每个控制对全部停止树中点仍有 R06 的统一 `O(n)` 覆盖界。

另一个边界必须保留：对初态 `(1,1)` 使用 `0∞`，有 `z_k=2(3/2)^k−(3/4)^k→∞`。本轮系统不再具有原稿/R06 的所有输入一致收敛性质；精确可行轨道仍趋于锥顶。它突破的是精度成本证明对所有横向分支收缩的依赖，不能包装为在保持原稿全部性质下的全面升级。
