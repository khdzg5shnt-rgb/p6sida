## 与 P6 的实际数学接口

WHS2019 的定义取初始状态空间上的任意 Borel 概率，不要求不变；全局量对受控 invariant partitions 取下确界。它与 R01 的提升不变测度的条件 KS 熵不是同一对象。

本次据该原件独立计算二进制锥体模型：归一化面积概率的两种 WHS 熵都是 `log 2`，锥顶概率的两种熵都是零。证明覆盖**所有**有限 Borel invariant partitions 的下界，另给明确分划达到上界，并没有只算一个反馈规则就冒充下确界。完整推导在 [MATHEMATICS.md](MATHEMATICS.md)。

还证明满锥体既无 clopen invariant partition，也无 maximally irreducible invariant partition：前者由连通性及没有一个控制字能保持整个锥体得到；后者由所有输入共同固定的锥顶得到。因此 WHS2019 带这些假设的全局变分结论不能直接套在此锥体上。这个适用性判断不排除别的研究已覆盖该例，也不证明新颖性。

## 完成补核：实际新增的数学与覆盖判断

完整推导见 [FULLTEXT_AUDIT.md](FULLTEXT_AUDIT.md)，本报告不以计算机有限检查代替一般证明。

1. **单位反证。** NWH 原文 discrete time 用二进制对数，权重却为 `exp(S_n f)`。因此常数平移是 `c/ln 2`，而非所写的 `c`。在 P6 二进制模型上，原文压力零势值为 1，Definition 3.4 的零压力层熵最大值却为 `ln 2`，直接反驳这些印刷约定同时采用时的 Theorem 3.13 / Corollary 3.15。不能将另一全势函数对偶公式的负无穷误说成实际 Definition 3.4 对所有测度都为负无穷。
2. **时变共轭的正面积反例。** `F_u(s,z)=(s,2z+su)`、`G_u=F_u/4`，输入为 `u=±1`，`Q=[0,1]×[-1,1]`，`K={1/2≤s≤1, |z|≤s}`。`π_n(x)=4^{-n}x` 是原文意义的时变共轭，满足 `π_n(Q)⊂Q`，但所有长度 n 的前缀强制给出 `r_F(n)=2^n`；目标系统每个输入都保持 Q，故 `r_G(n)=1`。自然单位下熵为 `ln 2` 与 0。映射光滑可逆，K 面积为 3/4；精确满足 Proposition 2.5 所要求的 admissible pair，而不是额外声称源系统整个 Q controlled invariant。压力及同一控制值概率的熵也已计算，故 Theorem 3.11 的等式同样失效，且不依赖单位问题。Kawan 的对应原文只给单向熵不等式，与反例一致。若补上每一时刻约束像集相等，等式可以直接证明；不是新重大主定理。
3. **负无穷边界与可保留的对偶。** 一维单点约束、两个控制、只有一个控制可行时，压力为该控制的势函数值；对另一个控制赋正概率的 Definition 3.4 熵为负无穷。NWH 的全体测度实值余域过强。统一自然单位、允许扩展值后，有限连续凸单调压力的变分对偶及最大值可由方向导数、Hahn–Banach 和 Riesz 完整证明。本轮给出该证明，确认 R02 使用的是已有方法的应用。

另外记录 NWH Definition 5.5 漏对数，以及 WHS 两处时间 / 指数系数遗漏并说明修复；它们不用于夸大新颖性。WHS 的初始状态概率、共轭、generator、clopen、Frostman 与 packing 机制已补审，但没有认证全部外部依赖或 §8 每个符号例。R03 二进制面积概率计算的 `τ=1` 与全分划下界的 `Nτ` 归一不受这些遗漏影响。

R01 的固定字母抽象提升图式分离证明在回查后仍成立于所列范围；本轮两篇原文没有直接给出那个精确图式命题，也不能因此认证其首创性。WHS 保留实际初始状态及受控分划，NWH 保留最小可行目录，而条件 KS 熵使用提升不变测度，三个对象不能混同。WHS 的全局定理不能直接套在没有 clopen 或 maximally irreducible 分划的锥体上；“不能套”仍不等于“新颖”。几何 / 内部复杂度分离观念及压力对偶已有覆盖这一判断保留，但引用边界修正为有条件、统一单位后的结论。
