# R01：失败尝试及边界

## 1. 从熵三元组或不变提升测度恢复控制成本

试探：以 `h(F)`、输入熵、state/fiber entropy 或 `supμ hμ(F|input)` 建一般等式。

P6 基线已经给出条件 KS 熵为零而三种控制熵可为正。R01 进一步固定输入字母，保持整个提升与因子图式的共轭类型及所有不变测度，仍使成本连续取不同值。失败类别：**精确目标被否定**。不是某一估计方法不够强；也不否定保留 Jacobian、可行初始投影或环境动力学的公式。

## 2. 把完整状态轨道因子补进纯提升原则

试探：总熵不足，是不是把整个状态轨道移位和 `e` 一起保留就足够？

R01 的状态因子具有共同商模型 `(Σm×[0,1])/(Σm×{0})`；整个轨道在正半径能读回输入标签，顶点才合并标签。其共轭仍不能恢复三个成本。失败类别：**增强后的目标仍被否定**。如果连初始状态 evaluation 也作为额外结构保留，exact count 可按 `Vw` 覆盖定义恢复；这只是定义重述，本轮没有将其冒充新变分原理。

## 3. 用 control set、可达性与复现挽救共同输入混沌

试探：P6 锥体缺少复现控制集，把这些条件补上是否能推出共同输入 Li–Yorke？

`x+=2x+v`、`D=(-1,1)` 已满足所筛的 genuine control set、内点前后局部可达、紧内子集统一有限 steering、每点 stationary recurrence；三种成本 `log 2`，整个提升满射。任意共同输入均有距离 `2^n|x−y|`，且一个输入实际上只有一个无限可行初始状态。失败类别：**该量词和所列假设下的目标被否定**，不能归因于 P6 锥体的不可达性或提升不满射。

成立范围：这里 recurrence 是每点存在复现可行控制，没有声称所有可行输入都复现，也没有证明允许不同输入的固定分配一定不能混沌。要求“对所有可行因果规则”则仍被统一反馈 `κ(x)=−x` 的恒等闭环否定。

## 4. 输入符号与分划闭包的错误替代

被排除的做法：把正输入移位熵当状态熵；把有限可行词的闭包当作每条无限状态轨道；拼接分别存在的一步可达边；针对每对初始状态重选输入。

这些做法没有建立同一系统内一个预先固定实现机制下的两状态反复接近与持续分离。原稿自身已有相应闭包/拼接反例。失败类别：**论证接口不成立**；未形成新的数学定理。

## 5. 只要求存在一个混沌反馈

零成本可行系统 `x+=x/2+v` 在 Q 上的一个固定连续反馈可实现经典满移位 Cantor 状态子系统。此检查没有否定“正成本也存在混沌反馈”的存在命题，但表明单纯存在性不解释正信息成本。

若附加条件直接要求一个连续闭环的正状态熵、或已给出满移位状态共轭，随后调用经典 chaos theorem 并无新的 control-entropy 到 chaos 推论。失败类别：**作为升级意义的论据不足**，不是所有存在命题被反例否定。

## 研究笔记中的修正

等长区间子覆盖引理最初草稿写了更一般的区间位置，端点论证没有完全展开。本轮收窄为“所有区间均在被覆盖区间内”，正好覆盖 inverse-cylinder intervals；完整 parity-spacing 证明已写入最终 TeX。没有把未经证明的较强版本保留为成果。初次 PDF 的两个长显示公式有溢出，已拆行并重编译、逐页查看。
